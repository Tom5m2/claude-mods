# token-bar

Мод для Claude Code: полоска над полем ввода, которая показывает, сколько токенов контекста использовано и сколько осталось, а также расход 5-часового лимита и время до его сброса.

## Установка

В терминальной сессии Claude Code:

```
/plugin install token-bar --marketplace Tom5m2/claude-mods
```

Подтвердите добавление маркетплейса (`y`) и выберите область установки.

Из обычного терминала:

```bash
claude plugin install token-bar --marketplace Tom5m2/claude-mods
```

В приложении Claude (вкладка Code), где `/plugin` не работает: нажмите **+** рядом с полем ввода → **Plugins** → **Add marketplace** с `Tom5m2/claude-mods` → **Add plugin**.
